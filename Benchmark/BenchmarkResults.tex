% Benchmark results for PolynomialCovers (Julia, parallel execution)

\paragraph{Benchmark Description}
This document summarizes the results of parallel benchmarks for the Julia package \texttt{PolynomialCovers}. The script evaluates two solvers: the companion solver and the cyclic solver, for polynomials of increasing degree. The benchmarks are executed using 4 Julia threads to exploit parallelism, and the results are shown for degrees from 5 to 50 in steps of 5.

\paragraph{Setup}
The script initializes Julia with 4 threads and disables BLAS multithreading to avoid interference. For each degree $n$, the following is computed:
\begin{itemize}
  \item \textbf{companion}: Time to compute roots using the companion matrix method.
  \item \textbf{cyclic}: Time to compute roots using the cyclic lift solver from \texttt{PolynomialCovers}.
  \item \textbf{err\_comp}: Maximum residual error for the companion solver.
  \item \textbf{err\_cyc}: Maximum residual error for the cyclic solver.
\end{itemize}

\paragraph{Comments}
\begin{itemize}
  \item The parallel execution significantly reduces the total runtime for the benchmarks, especially for higher degrees.
  \item Both solvers show very low residual errors, indicating high numerical accuracy.
  \item The cyclic solver is generally slower than the companion solver, but provides comparable accuracy.
  \item The script is thread-safe and avoids packages that are not compatible with Julia's multithreading.
\end{itemize}
